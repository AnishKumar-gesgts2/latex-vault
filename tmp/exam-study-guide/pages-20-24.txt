Problem 10(a). The xz-plane has equation y = 0, so a normal vector to the xz-plane is

                                                  ⟨0, 1, 0⟩.

A line perpendicular to the xz-plane must use this normal vector as its direction vector. Through (1, 2, 3),
the parametric equations are
                                     x = 1,     y = 2 + t,     z = 3.
Since two direction components are zero, the usual quotient-style symmetric form is not appropriate. A
symmetric-style description is
                                  x = 1,       z = 3,     y is free.

Common mistake to avoid. Do not say the direction vector is in the xz-plane. A line perpendicular to
a plane points in the normal direction to that plane.

Problem 10(b). The line x = y = z has direction vector

                                                  ⟨1, 1, 1⟩.

So a line through (1, 2, 3) parallel to it has parametric equations

                                 x = 1 + t,      y = 2 + t,         z = 3 + t.

The symmetric equations are
                                           x − 1 = y − 2 = z − 3.

Common mistake to avoid. The line x = y = z does not mean the new line must pass through the origin.
It only gives the direction ⟨1, 1, 1⟩.

Problem 11(c). The plane contains the line

                                  x = 2t,        y = 3 − t,        z = 1 + 3t.

A point on the line is obtained by setting t = 0:

                                                 P0 = (0, 3, 1).

The direction vector of the line is
                                                d = ⟨2, −1, 3⟩.
The plane also passes through
                                                Q = (1, −2, 3).
A second vector in the plane is
                                          −−→
                                          P0 Q = Q − P0 = ⟨1, −5, 2⟩.
A normal vector to the plane is
                                                         −−→
                                                 n = d × P0 Q.
Compute
                                           i j k
                                       n = 2 −1 3 = ⟨13, −1, −9⟩.
                                           1 −5 2
Use point Q = (1, −2, 3):
                                      13(x − 1) − 1(y + 2) − 9(z − 3) = 0.
Simplify:
                                        13x − 13 − y − 2 − 9z + 27 = 0
                                            13x − y − 9z + 12 = 0.
Thus
                                            13x − y − 9z + 12 = 0.

Common mistake to avoid. The point (1, −2, 3) is not necessarily on the given line. Use one point
from the line and the outside point to build a second vector in the plane.
